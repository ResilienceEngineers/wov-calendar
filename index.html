How to read this page — open if you're new here

This calendar plots recurring risk patterns and live events on one 12-month timeline, then flags where they converge.

  • Patterns (the calendar backbone) — recurring, evidence-based windows in five families: weather (hurricane, monsoon, cyclone, flood, wildfire, drought), cargo crime (holiday-period theft surges), cyber (holiday ransomware, tax-season phishing), conflict cycle (Sahel dry-season violence, Black Sea grain-corridor tension), and labour cycle (German wage rounds, French autumn strikes, US port-contract tension). Every pattern is in the pattern database (CSV) with its sources, search queries, and a metric we track to see if it is materialising.
  • Active events — live geopolitical threats, strikes, port closures, sanctions, realised disasters. Triaged daily.
  • Force-majeure declarations — operator FM statements from upstream fm-tracker + a global-press web search.
  • Custom analyses — your commodity-impact chains.

Convergence cluster = a time window where multiple bands overlap on the same region, industry, commodity, or chokepoint. Score 0–10; anything ≥5.5 surfaces. This is where a regional conflict + a weather peak + a labour action stack up and exacerbate each other.

Theory of Constraints for chokepoints. A maritime chokepoint is the constraint of global flow, so any single event touching one surfaces on the constraint board below — no convergence required.

Too much on screen? Use the filter bar above the calendar to narrow by pattern family, region, or chokepoints only.
